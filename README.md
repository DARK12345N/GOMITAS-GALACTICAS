# Gomitas Galácticas — Sitio estático

Archivo mínimo con HTML/CSS/JS para una tienda básica de prueba.

Cómo usar:

1. Abrir `index.html` en tu navegador (doble clic o arrastrar al navegador).
2. Añadir productos al carrito y enviar pedido (simulación, no hay pagos reales).

Si quieres que conecte esto a un backend, pasarela de pago (Stripe) o despliegue, dime y lo preparo.
